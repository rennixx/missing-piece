# Scope and MVP

## v0 — Methodology prototype

Goal: prove that an agent can reliably detect omissions with a disciplined reasoning process.

Deliverables:
- `SKILL.md`;
- reference rule documents;
- report template;
- hand-authored benchmark repositories/cases;
- example audit reports.

No scripts required.

## v1 — Public skill

Goal: publish a trustworthy, agent-agnostic skill.

Required detector families:
1. lifecycle completeness;
2. state-machine completeness;
3. symmetry/counterpart analysis;
4. mutation guards;
5. side-effect completeness;
6. failure/retry/recovery;
7. ownership and cleanup;
8. authorization/permission symmetry;
9. async/background job completeness;
10. operational completeness.

Required modes:
- standard audit;
- focused audit;
- changed-feature audit;
- explain-finding;
- re-audit.

## v1.1

- language/framework rule packs;
- stronger duplicate suppression;
- confidence calibration fixtures;
- optional machine-readable JSON report generated by the host agent;
- CI-oriented prompt/profile.

## v2

Introduce a local companion CLI only if benchmark evidence shows agent-only repository exploration is a bottleneck.

Possible CLI responsibilities:
- symbol/index extraction;
- dependency graph;
- route/schema inventory;
- state transition extraction;
- repository snapshot fingerprints;
- finding baseline comparison.

The CLI must not replace the skill's reasoning layer.

## Explicit exclusions for v1

Do not implement:
- account system;
- cloud backend;
- telemetry collection by Missing Piece;
- billing;
- IDE extension;
- autonomous fixing;
- runtime agent daemon;
- cross-repo graph;
- binary reverse engineering.
