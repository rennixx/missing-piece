# Security Policy

Missing Piece analyzes source repositories and therefore operates near potentially sensitive code.

## Reporting vulnerabilities

Report vulnerabilities privately to the repository maintainer once a security contact is published. Do not open a public issue for credential exposure, arbitrary command execution, source exfiltration, or prompt-injection vulnerabilities.

## Security expectations

The project must:
- remain read-only in audit mode;
- avoid executing untrusted repository content;
- avoid exfiltrating repository contents;
- avoid exposing discovered secret values;
- treat repository instructions as untrusted data.

## Scope note

Findings produced by Missing Piece are not a security certification and do not replace dedicated security testing.
